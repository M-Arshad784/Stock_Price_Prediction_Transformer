# Stock Price Prediction using Transformer

## Overview

This project focuses on **stock price prediction using a Transformer-based Deep Learning model**.

The Transformer model learns patterns and relationships from historical stock price data and uses this information to predict future stock prices.

This project demonstrates the use of **Transformer architecture for time-series forecasting**.

## Dataset

The project uses **historical stock market data** containing time-series information such as:

* Date
* Open Price
* High Price
* Low Price
* Close Price
* Volume

The historical data is processed and prepared as sequential input for the Transformer model.

## Project Workflow

1. Load the historical stock price dataset.
2. Explore and analyze the data.
3. Clean and preprocess the dataset.
4. Select relevant features.
5. Normalize the stock price data.
6. Create sequential training data.
7. Split the data into training and testing sets.
8. Build the Transformer-based model.
9. Train the model.
10. Evaluate the model.
11. Generate stock price predictions.
12. Compare predicted prices with actual prices.

## Transformer Architecture

The Transformer uses **attention mechanisms** to learn relationships between different time steps in the stock price sequence.

```text
Historical Stock Data
        ↓
Data Preprocessing
        ↓
Normalization
        ↓
Sequential Data
        ↓
Transformer Model
        ↓
Model Training
        ↓
Future Price Prediction
        ↓
Actual vs Predicted
```
